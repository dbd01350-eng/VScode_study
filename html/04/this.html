JavaScript this 키워드 실습

일반 함수와 화살표 함수에서의 this 바인딩 차이점 비교

1. 일반 함수의 this 객체 메서드
const user1 = {
  name: "철수",
  sayHi: function () {
    console.log("안녕 " + this.name); // this는 user1 객체
  }
};
user1.sayHi();
Console Output
안녕 철수

💡 일반 함수에서 this는 호출한 객체(user1)를 가리킵니다.

2. 화살표 함수의 this 상위 스코프
const user2 = {
  name: "영희",
  sayHi: () => {
    console.log("안녕 " + this.name); // this는 상위 스코프의 this
  }
};
user2.sayHi();
Console Output
안녕 undefined

💡 화살표 함수는 자신만의 this를 가지지 않고 상위 스코프의 this를 물려받습니다.
